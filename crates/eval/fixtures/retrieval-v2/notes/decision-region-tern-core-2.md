# Decision revised: cloud region for Tern Core

This replaces the earlier choice of cloud region for Tern Core. Tern Core switches its cloud region to eu-north, and the change takes effect on 26 July 2025. The telemetry side has been told so that dashboards and alert routes can be checked ahead of the switch. Questions go in the shared thread, and anyone who finds a stale reference to the old setting should fix it or flag it.
